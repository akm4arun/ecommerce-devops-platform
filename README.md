# E-Commerce DevOps Platform

Enterprise-style DevOps learning and portfolio project built using:

- AWS
- GitHub
- Python
- Docker
- Terraform
- Kubernetes
- GitHub Actions

## Objectives

This project demonstrates an end-to-end DevOps lifecycle:

1. Source control
2. Python application development
3. Automated testing
4. Containerization
5. Infrastructure as Code
6. CI/CD
7. Kubernetes deployment
8. Security scanning
9. Monitoring and logging
10. Deployment strategies
11. Rollback
12. Incident troubleshooting
13. Infrastructure automation

## Environments

- Development
- Staging
- Production

## Cost Optimization

The project is designed to maximize practical DevOps learning while minimizing AWS infrastructure costs.

Expensive AWS resources will be created only for specific labs and destroyed after use.
